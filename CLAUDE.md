# Приватный форк Bedolaga Cabinet (vpn1)

Приватная копия [BEDOLAGA-DEV/bedolaga-cabinet](https://github.com/BEDOLAGA-DEV/bedolaga-cabinet).
Это веб-кабинет (SPA на React + Vite) для нашего форка бота `aintlikeu/remnawave-bedolaga-telegram-bot`.
На сервере он работает за Caddy в `https://lk.vpn1.me`. Развёртывание описано в репозитории `newvpn`, `scripts/11-cabinet.sh`.

## Ветки и теги

- `main` — зеркало `upstream/main`. Сюда не коммитим.
- `vpn1` — наша рабочая ветка поверх **релизного тега** апстрима (сейчас `v1.80.1`: это та же версия, что работала из GHCR, commit `a693d30`).
- Выкатываем по тегам вида `<тег апстрима>-vpn1.<N>`, например `v1.80.1-vpn1.1`.
- `upstream` — только для чтения: push туда отключён.
- Этот `CLAUDE.md` апстрим игнорирует (`.gitignore`: `**/CLAUDE.md`). Файл отслеживается, потому что добавлен через `git add -f`. `.gitignore` апстрима не трогаем.

Обновление на новый релиз апстрима:

```bash
git fetch upstream --tags
git push origin 'refs/tags/*:refs/tags/*'
git rebase --onto vX.Y.Z <старый тег апстрима> vpn1
npm ci && npm run check && npm run type-check && npm test && npm run build
git tag vX.Y.Z-vpn1.1 && git push origin vpn1 --force-with-lease --tags
```

## Совместимость с ботом

- Кабинет обращается к API бота `/api/cabinet/*`. Caddy срезает префикс `/api` и проксирует запросы на `remnawave_bot:8080`.
- Релизы кабинета и бота выходят независимо. Обновляя кабинет на новый тег апстрима, проверьте, что используемые эндпоинты есть в развёрнутой версии бота: смотрите `app/cabinet` в форке бота.
- Если меняем контракт API в форке бота, правим кабинет в том же цикле и выкатываем их вместе.

## Правила изменений

- Дифф с апстримом держим минимальным. Тексты интерфейса лежат в `src/locales/<lang>.json`. Визуальные изменения по возможности делаем через темы и стили, не через переписывание компонентов.
- Параметры сборки задаются через build args в `Dockerfile` (`VITE_API_URL=/api`, `VITE_TELEGRAM_BOT_USERNAME`, `VITE_APP_NAME`, `VITE_APP_LOGO`). Секретов в кабинете нет и быть не должно: всё, что попадает в бандл, видно любому посетителю.

## Проверки
